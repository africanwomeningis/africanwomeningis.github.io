# African Women in GIS (AWiGIS) — Website

A single-page organization website for African Women in GIS, built from the
content on the official [StoryMap](https://arcg.is/1qvKi8) and
[Linktree](https://linktr.ee/africanwomeningis).

- `index.html` — the full site (open directly in a browser, no build step needed)
- `assets/logo.png` — the AWiGIS logo

The cover page shows our locations and founding story as a tap-through
story card (like Instagram stories) instead of a map, so it never has to
claim a level of geographic precision it can't back up.

Published version (shareable link): https://claude.ai/artifact/3niyQw8EgKX3GhHeHejBro
